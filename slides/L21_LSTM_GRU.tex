\sectionslide{Part 1}{The LSTM cell}

\begin{frame}{The idea before the equations}
  \begin{columns}[c]
    \begin{column}{0.5\textwidth}
      Give the network two things to carry:
      \begin{itemize}
        \item a \textbf{cell state} $\bm c_t$: long-term memory, a conveyor belt along the top of the cell that changes only in small, deliberate ways;
        \item a \textbf{hidden state} $\bm h_t$: what the cell chooses to show the outside world at this step.
      \end{itemize}
      \vskip0.5em
      Three \textbf{gates}, each a number between 0 and 1 per memory slot, decide:
      \begin{enumerate}
        \item \textbf{forget} $f$: how much of the old belt to keep;
        \item \textbf{input} $i$: how much of the new candidate to write;
        \item \textbf{output} $o$: how much of the belt to reveal.
      \end{enumerate}
    \end{column}
    \begin{column}{0.46\textwidth}
      \textbf{A notebook analogy}\\[0.3em]
      \renewcommand{\arraystretch}{1.25}
      \begin{tabular}{@{}ll@{}}
        cell state & the notebook \\
        forget gate & the eraser \\
        input gate & the pen \\
        output gate & which page you show \\
        hidden state & what you say aloud \\
      \end{tabular}
      \vskip0.6em
      \small A plain RNN has no eraser and no pen: it writes the whole page again from scratch at every word.
    \end{column}
  \end{columns}
\end{frame}

\analogyframe{The LSTM is a file in an office}
{A file moves from desk to desk. At each desk a clerk can remove old pages that no longer matter, add a new note, and decide which page to show at today's meeting. The file itself is never rewritten from scratch.}
{the file that travels between desks & \maps & the cell state $\bm c_t$ \pause\\
 removing outdated pages & \maps & forget gate $\bm f_t$ \pause\\
 adding a new note sheet & \maps & input gate $\bm i_t$ with candidate $\bm g_t$ \pause\\
 the page you show at the meeting & \maps & output gate $\bm o_t$, giving $\bm h_t$ \pause\\
 the old RNN: retyping the whole file at every desk & \maps & $\bm h_t=\tanh(W\ldots)$ every step \\}

\begin{frame}{The equations (Hochreiter \& Schmidhuber, 1997; forget gate: Gers et al., 2000)}
  \vskip-0.3em
  \begin{columns}[T]
    \begin{column}{0.52\textwidth}
      \begin{align*}
        \bm f_t &= \sigma\big(W_f[\bm h_{t-1},\bm x_t] + \bm b_f\big) && \text{forget}\\
        \bm i_t &= \sigma\big(W_i[\bm h_{t-1},\bm x_t] + \bm b_i\big) && \text{input}\\
        \bm g_t &= \tanh\big(W_g[\bm h_{t-1},\bm x_t] + \bm b_g\big) && \text{candidate}\\
        \bm o_t &= \sigma\big(W_o[\bm h_{t-1},\bm x_t] + \bm b_o\big) && \text{output}\\[0.3em]
        \onslide<2->{\bm c_t} &\onslide<2->{= \bm f_t\odot \bm c_{t-1} \;+\; \bm i_t\odot \bm g_t && \text{\alert{update the belt}}}\\
        \onslide<3->{\bm h_t} &\onslide<3->{= \bm o_t\odot \tanh(\bm c_t) && \text{what is shown}}
      \end{align*}
    \end{column}
    \begin{column}{0.45\textwidth}
      \begin{itemize}
        \item $[\bm h_{t-1},\bm x_t]$ means the two vectors stacked into one.
        \item $\sigma$ squashes to $(0,1)$: a gate is a dimmer switch, not an on/off switch, so it stays differentiable.
        \item $\odot$ is element by element: each memory slot has its own gates.
        \item The candidate uses $\tanh$ so it can write positive or negative values.
      \end{itemize}
      \vskip0.4em
      \small Read the belt update aloud: \emph{keep this much of the old, add this much of the new}.
    \end{column}
  \end{columns}
\end{frame}

\analogyframe{A gate is a fan regulator, not a light switch}
{A light switch is on or off. A fan regulator can be anywhere from 0 to 5. Every gate in an LSTM is a regulator, and each memory slot has its own set, turned by the network at every word.}
{regulator at 0 & \maps & gate value $0$: nothing passes \pause\\
 regulator at 5 & \maps & gate value $1$: everything passes \pause\\
 regulator at 3 & \maps & gate value $0.6$: part passes \pause\\
 a smooth knob, not a click & \maps & the sigmoid $\sigma$: differentiable, so it can be learned \\}

\begin{frame}{Why the gradient survives}
  \begin{columns}[T]
    \begin{column}{0.5\textwidth}
      Along the belt,
      \[ \bm c_t = \bm f_t\odot \bm c_{t-1} + \bm i_t\odot \bm g_t \]
      so (holding the gates fixed)
      \[ \frac{\partial \bm c_t}{\partial \bm c_{t-1}} = \operatorname{diag}(\bm f_t). \]
      No weight matrix, no $\tanh'$. Going $k$ steps back multiplies by $f$ values only.
      \vskip0.4em
      If the network learns $f\approx 1$ for a slot, its gradient passes back almost untouched: $0.99^{100}=0.37$, while $0.9^{100}$ would be $0.00003$.
    \end{column}
    \begin{column}{0.46\textwidth}
      \textbf{Plain RNN}: memory path is \emph{multiplicative}, the same matrix every step.\\[0.3em]
      \textbf{LSTM}: memory path is \emph{additive}, with a per-slot, per-step gate the network controls.
      \vskip0.6em
      \textbf{A practical detail that matters.} Initialise the forget-gate bias to a positive value (1 is common; Jozefowicz et al., 2015) so that a new network starts out \emph{remembering}. You will see in the case study what happens without it.
    \end{column}
  \end{columns}
\end{frame}

{Photocopy a page, then copy the copy, fifty times: the text fades away. Now send the original file along instead, with each desk only stamping a note on it: page one is still crisp at the fiftieth desk.}
{copy of a copy of a copy & \maps & plain RNN: multiply by $W_{hh}$ and $\tanh'$ every step \pause\\

\begin{frame}{What the gates cost}
  Each of the four blocks ($f, i, g, o$) is as big as a whole plain RNN layer:
  \[
    \text{RNN: } n(n+d)+n \qquad \text{GRU: } 3\big[n(n+d)+n\big] \qquad \text{LSTM: } 4\big[n(n+d)+n\big]
  \]
  \renewcommand{\arraystretch}{1.25}
  \begin{tabular}{@{}lrrr@{}}
    \toprule
    & \textbf{Plain RNN} & \textbf{GRU} & \textbf{LSTM} \\ \midrule
    $d=3$, $n=4$ & 32 & 96 & 128 \\
    $d=100$, $n=128$ (a word-embedding model) & 29{,}312 & 87{,}936 & 117{,}248 \\ \bottomrule
  \end{tabular}
  \vskip0.8em
  \small Libraries can differ slightly. Keras's GRU by default keeps two bias vectors per gate (\texttt{reset\_after=True}), giving $3[n(n+d)+2n]=88{,}320$ for the second row. Check with \texttt{model.summary()}.
\end{frame}

\sectionslide{Part 2}{The GRU: two gates instead of three}

\begin{frame}{Gated recurrent unit (Cho et al., 2014)}
  \begin{columns}[T]
    \begin{column}{0.5\textwidth}
      \begin{align*}
        \bm z_t &= \sigma\big(W_z[\bm h_{t-1},\bm x_t]+\bm b_z\big) && \text{update}\\
        \bm r_t &= \sigma\big(W_r[\bm h_{t-1},\bm x_t]+\bm b_r\big) && \text{reset}\\
        \tilde{\bm h}_t &= \tanh\big(W_h[\bm r_t\odot\bm h_{t-1},\,\bm x_t]+\bm b_h\big) && \text{candidate}\\[0.3em]
        \bm h_t &= (1-\bm z_t)\odot\bm h_{t-1} + \bm z_t\odot\tilde{\bm h}_t
      \end{align*}
      \vskip0.4em
      \small Conventions differ: PyTorch writes the last line with $\bm z_t$ and $1-\bm z_t$ swapped. Same model, the gate just means the opposite.
    \end{column}
    \begin{column}{0.46\textwidth}
      \textbf{What changed from LSTM}
      \begin{itemize}
        \item No separate belt: $\bm h_t$ is both memory and output.
        \item Forget and input are \emph{tied}: one gate $z$ decides the mix. Writing new information automatically erases the same amount of old.
        \item The reset gate $r$ decides how much of the past the candidate may look at.
        \item No output gate: the cell cannot hide what it remembers.
      \end{itemize}
      \vskip0.4em
      The memory path is still additive, so gradients survive the same way.
    \end{column}
  \end{columns}
\end{frame}

\analogyframe{GRU versus LSTM: a mixer tap versus two taps}
{A bathroom with two taps lets you run hot and cold independently, even both fully open. A single-lever mixer gives one control: turning towards hot takes away cold.}
{two separate taps & \maps & LSTM: forget $f$ and input $i$ set independently \pause\\
 both taps fully open, the bucket fills & \maps & $f=1,\ i=1$: the LSTM can add up, count \pause\\
 the single mixer lever & \maps & GRU: one update gate $z$ mixes old and new \pause\\
 more hot always means less cold & \maps & writing new always erases the same share of old \\}

\begin{frame}{Choosing between them}
  \small
  \renewcommand{\arraystretch}{1.3}
  \begin{tabular}{@{}>{\raggedright}p{3.1cm}>{\raggedright}p{3.2cm}>{\raggedright}p{3.2cm}>{\raggedright\arraybackslash}p{3.6cm}@{}}
    \toprule
    & \textbf{Plain RNN} & \textbf{GRU} & \textbf{LSTM} \\ \midrule
    Gates & none & update, reset & forget, input, output \\
    State carried & $\bm h$ & $\bm h$ & $\bm h$ and $\bm c$ \\
    Weights (same $n$) & $1\times$ & $3\times$ & $4\times$ \\
    Long-range memory & poor & good & good \\
    Can count / accumulate & no & weakly (writing erases) & yes (add with $f=1$, $i=1$) \\
    Reach for it when & short sequences, teaching & smaller data or compute budget & the default; long or structured sequences \\ \bottomrule
  \end{tabular}
  \vskip0.8em
  Large comparisons (Chung et al., 2014; Jozefowicz et al., 2015; Greff et al., 2017) found no clear winner between GRU and LSTM across tasks. Try both; tune the size and learning rate first.
\end{frame}

          \node[io,minimum size=0.45cm,font=\tiny] (x\t) at (\t,0) {$x_\t$};
          \draw[arr] (x\t)--(n1\t); \draw[arr,visible on=<2->] (n1\t)--(n2\t); \draw[arr,visible on=<3->] (n2\t)--(n3\t);
        }
        \foreach \l in {1,2,3} { \foreach \t [evaluate=\t as \u using int(\t+1)] in {1,2,3} { \draw[rec,visible on=<\l->] (n\l\t)--(n\l\u); } }
        \foreach \l in {1,2,3} { \node[font=\scriptsize,anchor=east,text=inksoft,visible on=<\l->] at (0.45,\l) {layer \l}; }
      \end{tikzpicture}
    \end{column}
    \begin{column}{0.52\textwidth}
      The hidden states of layer 1 are the input sequence of layer 2.
      \begin{itemize}
        \item Lower layers tend to capture local patterns (characters, short phrases); higher layers longer structure.
        \item Two to four layers is typical. Beyond that, training gets hard without residual connections.
        \item Put dropout \emph{between} layers.
      \end{itemize}
      \vskip0.4em
      In Keras, every layer except the top one needs \texttt{return\_sequences=True}, so it hands the next layer a full sequence instead of only its last state.
    \end{column}
  \end{columns}
\end{frame}

\begin{frame}{What the game was teaching}
  \begin{itemize}
    \item \textbf{Forget means keep.} $f=1$ keeps the memory; $f=0$ erases it. Most people closed it on level 1 and lost the number.
    \item \textbf{Overwrite} needs two gates at once: $f=0$ to erase and $i=1$ to write.
    \item \textbf{Count} works because the belt adds: $f=1, i=1$ on every star.
    \item \textbf{Output} is separate from memory. The cell can remember without saying anything, which is what stops ``plural'' from leaking into every word.
    \item \textbf{GRU}: one gate $z$ moves memory and new input in opposite directions. Store and overwrite are easy; counting is impossible, because writing always erases.
  \end{itemize}
  \vskip0.6em
  In a trained network these gates are not 0 or 1 but values in between, learned by gradient descent, one per memory slot.
\end{frame}

\begin{frame}{To take away}
  \begin{enumerate}
    \item The LSTM keeps a cell state that changes only by gated multiplication and addition: $\bm c_t = \bm f_t\odot\bm c_{t-1}+\bm i_t\odot\bm g_t$.
    \item Forget, input and output gates are sigmoids in $(0,1)$, learned per memory slot and per step.
    \item The additive path lets gradients travel far back; initialise the forget bias so the cell starts by remembering.
    \item A GRU ties forget and input into one update gate, has no separate cell state, and uses 3 weight blocks instead of 4.
    \item Bidirectional RNNs read both ways when the whole sequence is available; stacked RNNs build hierarchy.
  \end{enumerate}

  \textbf{Coming up:} CNNs (Lectures 22--23), then reinforcement learning (Lecture 24), where an LSTM can supply the agent's state when one observation is not enough.
