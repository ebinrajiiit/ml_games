You are the gates

A one-slot LSTM. A row of tokens arrives one at a time. Before each token you set three gates, then press Step:

ct = f·ct−1 + i·xt     output = o·ct

  • f, forget gate: 1 keeps the old memory, 0 erases it. (Yes, “forget = 1” means keep.)
  • i, input gate: 1 adds the current token to the memory, 0 ignores it.
  • o, output gate: 1 shows the memory, 0 stays silent.

Think of the belt as an office file moving from desk to desk. At each desk: keep the old pages or remove them (f), add today's note or not (i), show the file at the meeting or keep it closed (o).

We drop the tanh and use only 0 or 1 so the numbers stay readable. In a real LSTM every gate is a value between 0 and 1, learned per step.

Five levels, 20 points each. On ASK tokens the output must be the right number. On every other token the output must be 0. Each mistake costs 5 points.

What the levels were showing

Store and recall. Write with i = 1 once, then hold with f = 1 and keep o = 0 until asked.

Overwrite. A new value needs f = 0 and i = 1 on the same step: erase and write together.

Count. The belt adds. f = 1 and i = 1 on each star keeps a running total. A plain RNN, which squashes everything through tanh at every step, has no clean way to do this.

Recall twice. Showing the memory (o = 1) does not use it up.

GRU. One gate z mixes old and new: h = (1 − z)·h + z·x. Storing and holding are easy. Counting is impossible, because writing always erases the same share of what was there.
